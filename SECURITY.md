# Security Policy

This repository documents [GHSA-965c-763c-88jm](https://github.com/better-auth/better-auth/security/advisories/GHSA-965c-763c-88jm), a **public, already-patched** issue in better-auth (`>= 1.4.0-beta.18`, `< 1.7.7`). The fix is **1.7.7** (purpose isolation). Upgrade affected deployments.

## Reporting a vulnerability

- Do **not** open a public issue for a new better-auth vulnerability. Follow [better-auth security advisories](https://github.com/better-auth/better-auth/security/advisories).
- Bugs in this PoC (false positives, script errors, docs) may be reported as GitHub issues on this repository.

## Authorized use only

Run the script only against systems you own or have explicit written permission to test. Unauthorized access to computer systems is a crime.
